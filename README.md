# Система моніторингу засобів індивідуального захисту

Програмний прототип локальної інтелектуальної інформаційної системи, призначений для автоматизованого відеомоніторингу та детекції порушень правил використання засобів індивідуального захисту (ЗІЗ). На основі інтегрованої моделі комп'ютерного зору система розпізнає ключові об'єкти (працівників, захисні каски, сигнальні жилети) та генерує картки потенційних інцидентів. Архітектура рішення реалізує концепцію human-in-the-loop, де результати машинного висновку є рекомендаційними та підлягають обов'язковій валідації оператором.
## Основні функції

- Аналіз зображень та відеофайлів
- Імітація роботи багатокамерної системи через два логічні слоти в інтерфейсі (без прямого підключення апаратних IP-камер)
- Ідентифікація п'яти цільових класів (person, helmet, no_helmet, vest, no_vest) з оцінкою впевненості моделі
- Генерація карток інцидентів: автоматичне створення звітів, що містять візуальне підтвердження, опис статусу ЗІЗ та розрахунковий пріоритет перевірки (risk_score)
- Класифікація інцидентів людиною (Confirmed, False Positive, Ignored) з можливістю відміни останньої дії
- Панель управління (Дашборд), система фільтрації подій, адміністрування облікових записів та ведення журналів робочих змін
- Підтримка Active Learning: формування датасету донавчання з хибно класифікованих кадрів

Під час аналізу відео обробляється кожен десятий кадр. Два канали є логічними слотами інтерфейсу; виклики моделі виконуються послідовно.

## Склад проєкту

- main.py — точка входу, ініціалізація локального сховища та запуск графічного інтерфейсу (GUI)
- ui.py — модуль фронтенду на базі PySide6, що реалізує робочу область оператора, аналітичні дашборди та інструменти навігації
- detector.py — модуль інференсу: завантаження ваг, обробка потоку (OpenCV), мультиоб'єктний трекінг та логіка просторового зіставлення атрибутів (ЗІЗ) з об'єктом (person)
- store.py — модуль бекенду (ORM-сумісний), що забезпечує транзакційну взаємодію з БД SQLite для збереження метаданих інцидентів та ведення логів
- config.py — глобальна конфігурація проєкту: гіперпараметри моделі, індексація класів та маршрутизація файлової системи
- requirements.txt — специфікація Python-залежностей
- current_model.pt — серіалізовані ваги натренованої архітектури YOLO11m

## Дані та зберігання

Застосунок зберігає дані локально в каталозі `data/`:

- monitoring_ziz.sqlite3 — реляційна БД для збереження метаданих (облікові записи, сесії, інциденти, аудиторський слід). У записах інцидентів зберігаються лише відносні шляхи до медіафайлів
- raw_frames/ — оригінальні кадри інцидентів без накладених Bounding Boxes (використовуються для подальшого експорту)
- incidents/ — структурований архів візуальних матеріалів за статусами:
  - fixed_new/ (картки pending, що очікують рішення оператора)
  - confirmed/, false_positive/, ignored/ (пост-верифікаційні стани)
  - deleted/ (м'яке видалення з активного перегляду)
  - resolved/ (кадри, де система підтвердила подальше виправлення статусу ЗІЗ для відстежуваної особи)
- active_learning/ — цільове сховище кадрів, позначених як False Positive, для майбутніх ітерацій навчання
- recovery/ — службова директорія для ізоляції "осиротілих" файлів під час перевірки цілісності бази
- uploads/ — зарезервована директорія для майбутньої інтеграції функції пакетного імпорту

## Модель і набір даних
Детекція здійснюється за допомогою нейромережевої архітектури Object Detection — YOLO11m (Medium). Процес навчання, оптимізації гіперпараметрів та аугментації проводився ізольовано у хмарному середовищі Kaggle, після чого ваги фінальної моделі (best.pt) було експортовано та інтегровано в систему.
Завдяки модульній архітектурі, застосунок підтримує динамічну заміну файлу ваг current_model.pt на будь-яку іншу сумісну модель (натреновану на ідентичних 5 цільових класах) без зміни вихідного коду проєкту.

Навчальний набір: [Personal-Protective-Equipment (PPE) Dataset](https://www.kaggle.com/datasets/ndomalau/personal-protective-equipment-ppe-dataset)

Код експериментального навчання: [Kaggle Notebook](https://www.kaggle.com/code/annalozova/augmentated)
